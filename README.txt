LOTTO FINAL PICK 웹페이지
============================

핵심 원칙
- 번호를 새로 계산하지 않습니다.
- 반드시 Excel의 FINAL_자동발급 시트에서 순번=1 행의 N1~N6을 읽습니다.
- 최신 실제 당첨 회차 + 1을 다음 회차로 표시합니다.
- 6개 번호가 1~45 범위/중복 없음인지 검증합니다.
- 검증 실패 시 임의 번호를 만들지 않고 오류를 표시합니다.

[가장 쉬운 사용법 - Python 불필요]
1. data 폴더 안의 '원본엑셀.xlsx'를 매주 최신 Excel로 교체합니다.
2. '실행하기.bat'를 더블클릭합니다.
3. 로컬 HTML은 브라우저 보안 때문에 Excel 자동 접근이 막힐 수 있습니다.
   그 경우 화면에 나타나는 '원본 Excel 파일 선택'을 한 번 눌러 최신 Excel을 선택하면 됩니다.

[인터넷 링크로 사용]
이 폴더는 정적 웹사이트라서 Netlify Drop 등에 그대로 올릴 수 있습니다.
1. 아래 공식 페이지를 엽니다:
   https://app.netlify.com/drop
2. LOTTO_WEB 폴더를 그대로 드래그합니다.
3. 생성된 netlify.app 주소로 웹페이지에 접속합니다.
4. 웹으로 배포된 상태에서는 data/원본엑셀.xlsx를 자동으로 읽습니다.
5. 매주 Excel을 교체한 뒤 같은 사이트에 폴더를 다시 드래그해 업데이트하면 됩니다.

주의:
- 공개 웹사이트에 Excel을 함께 올리면 Excel의 모든 시트가 인터넷에 공개됩니다.
- Excel을 공개하고 싶지 않다면 로컬 실행 방식으로 사용하세요.
- 웹페이지는 '당첨확률 증가', '당첨 보장' 등의 표현을 사용하지 않습니다.

현재 첨부 Excel 검증 결과
- FINAL_자동발급 발견: 예
- 1순위: 10, 27, 31, 33, 37, 42
- 최신 실제 회차: 1236
- 다음 회차: 1237
